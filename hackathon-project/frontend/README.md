# Frontend

Source code for the web client. Built with `/build-frontend` using the **frontend-development** skill.

## Setup
```bash
<npm install>
cp .env.example .env   # set VITE_API_BASE_URL
<npm run dev>
```

## Structure
`src/api` · `src/components` · `src/pages` · `src/hooks` · `src/context` · `src/styles` · `src/utils`

## Notes
- Follow field names in `../architecture/api-contracts.yaml`.
- Tests live in `../tests/frontend/`.
